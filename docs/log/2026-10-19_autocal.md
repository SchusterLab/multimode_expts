## Decisions (seb)

- Coupler set point 0.30 mA (the transduction set point since 2026-10-05; the 10-16/17 calibrations by another user
  were at 0.12 / 0.25 mA, so their manipulate / storage values do not apply).

- Every step keeps its plot; a review page per run.
- Package location `experiments/autocal/`; developed in a worktree, merge into main only with seb's OK.

## Found

- The notebooks fit every step but apply the fit without a quality check.
- The multiphoton pi/2 entries: only g0-e0 is calibrated and used (sigma 0.02, gain close to the pi gain); the other
  pi/2 entries hold leftover values (e.g. frequency 0 for e_n-f_n). The notebook's pi/2 scans centred on the pi values
  therefore land near the right g0-e0 pi/2 gain; autocal seeds the pi/2 from its own gain instead.
- The notebook's error-amp postprocessor writes any photon-0 frequency (also g0-e0) into the M1 storage row.
- M1-S4 is 872.39 MHz in today's dataset (0.25 mA) vs 878.32 MHz at 0.30 mA (`CFG-M1-20261012-00012`).
- A check on flat (mock) data passed at first (zero residuals -> infinite signal-to-noise); fixed, with a test.
- Time estimate of the default plan: ~1.5 h of acquisition (56 steps); seb's manual run takes 2-3 h.
